# SkillLoop

SkillLoop is a student peer-to-peer learning and knowledge-sharing platform.

It helps college students connect with other students, find learning partners, share skills, ask for academic help, and collaborate through study groups.

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS

## Main Features

- Student Profiles
- Skill-Based Matching
- Help Requests
- Private Messaging
- Study Groups

## Project Status

Currently under development as a semester project.
